PAVEMENT STRUCTURAL CAPACITY TESTING

Falling Weight Deflectometer (FWD / HWD) Support

Pavement bearing capacity evaluation relies on micro-inch deflection accuracy under dynamic impulse loads. PTS provides reference calibration complying with AASHTO R32, geophone sensor array rebuilds, load cell amplifier testing, and layer moduli back-calculation support.

Book FWD Calibration Audit Interactive Deflection Simulator
PROTOCOL 01

Geophone Beam Calibration

Relative and reference gain calibration for all 7-9 geophones to verify linearity against NIST-traceable reference towers.

PROTOCOL 02

Load Cell Verification

Dynamic pulse force validation across 4 drop heights, verifying 30kN to 120kN impact load cell signal amplifiers.

PROTOCOL 03

Hydraulic Catch Maintenance

Overhaul of hydraulic cylinders, catch release solenoids, directional control valves, and pressure accumulator damping.

PROTOCOL 04

Back-Calculation Workflows

Integration with ELMOD, BAKFAA, and Modulus 6.0 software suites for asphalt residual life and structural overlay design.
